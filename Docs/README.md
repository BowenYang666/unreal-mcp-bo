# Unreal Engine MCP Documentation

Welcome to the documentation for the Unreal Engine Model Context Protocol (MCP) integration. This documentation will help you understand, set up, and use the MCP system with Unreal Engine.

## Contents

- [Tools](Tools/README.md) - All the tools that are available.
- [Editor and Asset Tools](Tools/editor_tools.md) - Logs, saving, asset rename/move/duplicate, and level management.
- [Reading Blueprints Guide](Tools/reading_blueprints.md) - How to discover and inspect existing Blueprints in your project.
- [Niagara Tools Guide](Tools/niagara_tools.md) - Create and edit Niagara particle systems.
- [Cascade Reader](Tools/cascade_tools.md) - Read legacy ParticleSystem emitters, LODs, modules, curves, and references without converting assets.
- [Navigation Tools Guide](Tools/navigation_tools.md) - Create NavMesh bounds, build navigation, and query agent paths.
- [Material Tools Guide](Tools/material_tools.md) - Create and edit Material graphs, update instance parameters and Parent, and inspect save results.
- [UMG Tools Guide](Tools/umg_tools.md) - Create and edit UMG Widget Blueprints.
- [Project Onboarding](copy_plugin_to_project.md) - Deploy/build the plugin, configure VS Code or Claude Code, launch, and verify connectivity.
